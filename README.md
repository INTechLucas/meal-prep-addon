# Meal prep – dépôt d'add-ons Home Assistant

Add-on **Cuisine (Claude)** : planification des repas, batch cooking du dimanche, stock et liste de
courses Lidl, avec un panneau dans Home Assistant et un serveur MCP pour Claude.

## Installation

Dans Home Assistant : Paramètres > Modules complémentaires > Boutique > ⋮ > Dépôts,
ajouter `https://github.com/INTechLucas/meal-prep-addon`, puis installer **Cuisine (Claude)**.

Voir [cuisine/DOCS.md](cuisine/DOCS.md) pour la configuration.

Add-on **Liseuse (Kobo)** : panneau de contrôle de la maison sur une liseuse Kobo (plugin KOReader) :
lumières, prises, thermostat, repas, recettes et séances. Voir [liseuse/DOCS.md](liseuse/DOCS.md).

Aucun secret n'est stocké dans ce dépôt : le jeton d'accès se saisit dans les options de l'add-on.
